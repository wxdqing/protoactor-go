# identitylookup 文档导航

这组文档对应 `server/libs/identitylookup`，用于说明该库的职责、核心调用链、生命周期、存储语义以及当前代码风险。

建议阅读顺序：

1. `overview.md`
2. `architecture.md`
3. `lifecycle.md`
4. `code-review.md`
5. `index.html`

文件说明：

- `overview.md`：用业务和接入视角解释这个库解决了什么问题。
- `architecture.md`：用开发者视角解释组件关系、关键抽象和核心流程。
- `lifecycle.md`：按时间顺序梳理启动、查询、激活、终止、关闭。
- `code-review.md`：列出当前实现中的高风险问题和验证结果。
- `index.html`：单文件离线可视化阅读入口，内含 UML 风格图。
